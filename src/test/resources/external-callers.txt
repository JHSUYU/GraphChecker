# GraphChecker APIs called from OUTSIDE this repository: the system trees'
# own source calls them (lucene-solr-checks, zookeeper-unified,
# hbase-unified).  They are not woven, so ConcolicHookAbiTest's catalog check
# cannot see them and a `git grep` of src/ finds no caller.  The trees compile
# against an older jar in ~/.m2, so a rename or a deletion here surfaces only
# when a campaign loads the new jar -- at SEED, as NoSuchMethodError, after
# the build is already green.
#
# Format: <class> <method> <return> <parameters...>; a class is named under
# edu.uva.liftlab.graphchecker.
# Also external, and checked by the compiler rather than here:
#   annotation.CausynthExceptionTarget, the known-bug marker on a target
#   throw (the unified HDFS tree: BlockTokenSecretManager,
#   FSImageFormatPBSnapshot; the ZooKeeper tree: FinalRequestProcessor); no
#   engine code reads it -- a target is a class and a line,
#   causynth.ExceptionTargetLineResolver -- but tools/lib/annotated.py
#   derives a case's target spec from it.

# The fault marker DoorWeave weaves by name before a door's throw (no hook
# catalog names it).
