## Q6 — the fix (class **(c) compose/lowering**, `compose/Composer.java`)

**F1 — the first break, one argument.** `Composer.java:714-715`
`Arms.pathCondition(path.decisions, Long.MAX_VALUE)` → `…, target.seq())`.
`pathCondition(decisions, before)` already drops `seq >= before` (`smt/Arms.java:705-714`) and
`Arms.wireArms` already applies exactly this rule to arms (`Arms.java:571`, `…, deliveredAt`); the

decision. Effect: no obligation verdict changes (COMPOSE only); the 7 paths stop being
self-contradictory and the core moves to the handoff families (`$MY/c18/smt/nofatalpolarity_base.smt2`).
Gate invariant to add: **π_p is the prefix strictly before the target observation** — no
`path_fatal__i` may carry a decision conjunct at the anchor's `seq`.

**F2 — the second break.** `Composer.java:1086-1099 pairedArm`: drop/widen the
`movableRoot(delivered.text)` filter at :1092 — an attested producer arm must be used whenever the
producer occurrence has more than one world in the corpus, not only when its expression names a
declared movable root; the freedom in a key *identity* is which world the producer was in.
Fail-closed alternative: keep the literal but raise a BLOCKING gap naming the pinned declared port,
so the claim cannot be `NO_SUPPORTED_WITNESS` while a pin it created closes the witness. With F1+F2
path 3 is SAT — measured, `$MY/c18/smt/p3_nopol_noexport.smt2` → `sat`; the witness is "dn1 expired
182905 at its refresh **and** nn0's rotation-2 no longer exported it", joining a02cd2be (dn1) with
af9801b6/14eb8358 (nn0). Ledger effect: the 6 ADMITTED stay ADMITTED and become *usable*; a witness
(SAT_CANDIDATE) follows only if the 5 BLOCKING ADMISSION_GAP rows are also settled.
