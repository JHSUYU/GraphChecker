## 8. Running a case (any branch, liftlab)

1. **A snapshot of the branch:** `GC_REPO=~/GraphChecker bash tools/lib/worktree-add.sh /u/vnr3ne/gc-run/<name> <commit>
   --detach`, then `cd` there and run `mvn -q -o package -DskipTests` on a Maven host.
2. **The trees:** `GC_TREES=<tree set> GC_M2=<maven repository> bash experiments/<sys>/prepare-trees.sh [tree...]` on a
   Maven host. It clones each tree's fork branch from GitHub, builds it, and runs every workload natively once.
3. **One or several cases at once,** from lift11: `env GC_OUT=<dir> GC_TREES=<tree set> GC_M2=<maven repository>
   LIFTS="<workers>" CAUSYNTH_CUSTOM_JDK_HOME=<vm image>/j2sdk-image CASE_TIMEOUT_SECONDS=21600 PRUNE=0
   CASES="<case> ..." bash <snapshot>/tools/rounds/launch-round.sh <snapshot> <ROUND>`. The run is
   `<GC_OUT>/accept-<ROUND>-<case>` (`hdfs-` dropped).
   - Each case alone, one after another: `/bigtemp/vnr3ne/analysis/buggy-detect-exclusive-2026-10-28/series-E1.sh`
     (copy it, set the case list).
   - The whole exploration: `series-N1.sh` (`CAUSYNTH_STREAM_STOP_AT_WITNESS=false`).
4. **Read:**
   - `summary.tsv`, and `out/<case>/schedule/final/{confirm,reproduce}.json`;
   - `tools/analysis/vacuity.py` for an UNSAT;
   - `tools/analysis/smt-legend.py` for the formula;
   - `results/<sys>-buggy/final-stats.py --cases <cases.tsv>` for a table.
