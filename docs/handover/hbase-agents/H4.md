## (d) Lessons and traps (non-obvious)

1. **A guard the VM cannot state makes the UNSAT vacuous, or the claims wrong.** None of the following gets a term:
   - a sum over a map's entries;
   - a shaded Guava `ImmutableMap`;
   - an `AtomicInteger`;
   - a method-reference lambda's return (no provenance).

   Workaround: keep the value in an `int` field, or in `Integer`s in a HashMap or LinkedHashMap, written where the state changes. Evidence: hbase-adhoc-22's phi got the term INSTANCE_FIELD 32#24 only after e8d5308c47 (readings, HC10). nsrg's guard got its term after cabb055aad and c168e5b0ce.
2. **A String `equals` over a descriptor's TreeMap is concrete.** The decision then has no term, and COMPOSE finds SAT through unrelated chains that CONFIRM refutes. Evidence: in HC14-nsrg, the refuted claims in `schedule/final/refuted/0001` and `0002` carry a CreateTable#retry1 fault plus moveServers and startup-flush ORDER rows, none of which is the namespace check. Give the check a tracked count (985a0dfe91).
3. **CONFIRM's "moves nothing" shortcut** refused real seed-path re-pairings: the witness ran the seed path with a STATE arm re-paired. Fixed by a9aead2fa: it checks the valuation's repairedArms and fills each arm's closure readers from that arm's writes. Evidence: HC13-22, 4 refusals.
4. **Make one fault one lost request.**
   - HBase client retries (15 by default, `AsyncRpcRetryingCaller`) absorb a single REQUEST or RESPONSE fault, and a retried request with the same nonce returns the same procedure.
   - Use a dedicated connection with retries=0 (04), or one attempt in automatic mode for the one put that matters (nsrg).
   - This beats raising world depth to the retry count.
5. **Async reply chains.** An admin call issued inside a reply callback of a poll gets an anchor minted from the poll count. The poll count differs in the slower seed replay, so the result is MISSING. Evidence: HC11-21, planned 7be160aff4b342f7, ran b6701a92041c9536. Avoid the chain in the workload (23ff06c9ba).
6. **Two-master tests elect differently in replay.** Evidence: HC7-08 MISSING, master1 was active in the replay. Fix: start the first master alone in automatic mode (fc48a0f017).
7. **Finding target occurrence selectors.** Use a SEED-only run (`STOP_AFTER=SEED`, `OCCURRENCE=<placeholder>`). `DECLARED_TARGET_OCCURRENCE_UNOBSERVED` lists every observed `<node>#epoch/region/REGION.<uuid>#k`.
   - Evidence: 22's selector is `REGION.ebc27075#2`, and #1 is the truncated table's own creation.
   - 04's selector is `REGION.98cba534#2`, and #1 is the test's disable.
8. **ORDER across a procedure step and a client call a second later was not realized by CONFIRM.** Evidence: HC14's "did not exit within 300000 ms" on HBASE_RPC SEND marks. Prefer a fault that opens the window, plus a test hook that holds the order inside it.
9. **Waiting and launching.**
   - A waiter must give the job about 90 s of grace before it is visible.
   - A head charges its full heap for its whole life, so a host with a head runs no replays. Use all 14 workers.
