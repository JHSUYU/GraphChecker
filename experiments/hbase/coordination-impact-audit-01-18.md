# Coordination and failure-impact audit: findings 1–18

Scope: HBase worktree at `1790942bb2d46f41f1b4aed94db85e6f5bd18a1a`. This review checks the **new user criterion**: a branch over ad hoc coordination state raises an exception that fails a key request or thread. `Pass` means the existing test reaches the predicate and the production caller path establishes failure propagation; it does **not** mean an end-to-end cluster incident or global novelty has been proved. `Insufficient` means the production premise needed to reach the predicate is not established. `Fail` means the finding does not meet the coordination criterion. Deliberately red tests fail a final assertion **after** capturing the named exception; the JUnit assertion failure itself is not the HBase failure.
