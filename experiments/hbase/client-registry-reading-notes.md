## Candidate disposition

1. **Sparse Meta replica znode array index:** confirmed source path and possible asynchronous creation of replica 2 before replica 1 in `ModifyTableProcedure.assignNewReplicasIfNeeded` and `RegionStateStore.mirrorMetaLocation`. `ZKConnectionRegistry` allocates array by child count and indexes by replica ID. The exception is swallowed and logged by `FutureUtils.addListener`, leaving the public future incomplete. **Rejected as new** because [HBASE-25280](https://issues.apache.org/jira/browse/HBASE-25280) is specifically “ArrayIndexOutOfBoundsException in ZKConnectionRegistry.”
2. **Custom replication endpoint with null cluster key:** [HBASE-21857](https://issues.apache.org/jira/browse/HBASE-21857) explicitly permits null `clusterKey` for custom endpoints; `ReplicationPeerManager.checkClusterKey` returns for a non-HBase endpoint. A peer selected by `RawAsyncHBaseAdmin.checkAndSyncTableToPeerClusters` then calls `ReplicationPeerConfigUtil.getPeerClusterConfiguration`, which invokes `ConnectionRegistryFactory.tryParseAsConnectionURI(null)` and causes NPE at `new URI(clusterKey)`. `RawAsyncHBaseAdmin` catches `IOException` only, and `FutureUtils.addListener` logs unchecked callback failures without completing the outer future. This is a **plausible untested** admin hang, outside the strict explicit `if`/`throw` shape requested for counted findings. No ledger entry or targeted test was made.
3. **URI case and trailing parent slash:** factory lookup normalizes scheme but concrete URI factories assert exact lowercase; under assertions, an uppercase scheme yields `AssertionError`. URI validation also allows a trailing parent slash that `ZNodePaths.joinZNode` would extend to a double slash. Both are input normalization/validation cases, not demonstrated control-plane/data-plane coordination defects; no test or finding made.
4. **Prefix-colliding nonnumeric Meta child:** `ZNodePaths.isMetaZNodePrefix` admits nonnumeric siblings and `getMetaReplicaIdFromZNode` can throw `NumberFormatException`. No production writer of that child was established. This remains unverified and may overlap the known registry issue.
