# Provisional novelty review, 2026-09-18

The ledger counts a finding provisionally toward 50 when a new HBase unit test reproduces the named exception, a hand-composed SMT model checks the causal ordering and a control, and targeted searches of ASF Jira and `apache/hbase` GitHub issues/PRs find no exact report. This is an auditable search result, not proof that no prior report exists. Discovery of an exact predecessor removes the count.
