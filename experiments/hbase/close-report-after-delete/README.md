# Accepted CLOSED report retried after table deletion

This hand-composed [SMT model](close-report-after-delete.smt2) joins a RegionServer's original CLOSED report and retry (WIRE family) with the master's `RegionStates` membership before and after table deletion (STATE family). It models the conditional exception path in [`AssignmentManager.java:1305-1315`](/u/vnr3ne/hbase/hbase-server/src/main/java/org/apache/hadoop/hbase/master/assignment/AssignmentManager.java:1305). Run `/tmp/hbase-z3/usr/bin/z3 -smt2 close-report-after-delete.smt2`: a lost ACK, deletion, then retry gives `sat`; retry before deletion gives `unsat` for the missing-region exception; delivered ACK gives `unsat` for a retry caused by lost acknowledgement.

[`HRegionServer.java:2373-2417`](/u/vnr3ne/hbase/hbase-server/src/main/java/org/apache/hadoop/hbase/regionserver/HRegionServer.java:2373) retries the same request after an RPC `ServiceException`. The first report's modern procId is extracted at [`AssignmentManager.java:1229-1234`](/u/vnr3ne/hbase/hbase-server/src/main/java/org/apache/hadoop/hbase/master/assignment/AssignmentManager.java:1229). [`DeleteTableProcedure.java:431-439`](/u/vnr3ne/hbase/hbase-server/src/main/java/org/apache/hadoop/hbase/master/procedure/DeleteTableProcedure.java:431) calls `AssignmentManager.deleteTable`, which removes every table region from `RegionStates` at [`AssignmentManager.java:1207-1217`](/u/vnr3ne/hbase/hbase-server/src/main/java/org/apache/hadoop/hbase/master/assignment/AssignmentManager.java:1207). On retry, the missing node makes `updateRegionTransition` throw `UnexpectedStateException`; [`reportRegionStateTransition`](/u/vnr3ne/hbase/hbase-server/src/main/java/org/apache/hadoop/hbase/master/assignment/AssignmentManager.java:1282) catches it as `IOException` and places its text in the response error field. The RegionServer stops retrying on an error response.

The new [`TestCloseReportRetryAfterTableDelete.java:53`](/u/vnr3ne/hbase/hbase-server/src/test/java/org/apache/hadoop/hbase/master/assignment/TestCloseReportRetryAfterTableDelete.java:53) has a real assignment and CLOSE, checks the first report succeeded and carried a modern procId, removes the table assignment state, then sends that exact report again. Its red [Surefire report](/u/vnr3ne/hbase/hbase-server/target/surefire-reports/org.apache.hadoop.hbase.master.assignment.TestCloseReportRetryAfterTableDelete.txt) has one deliberate assertion failure whose response says `Region is not known`. The test replays the request directly; it does not inject an actual RPC response loss. The response loss is justified by the production retry loop and modeled as an ordering assumption.
