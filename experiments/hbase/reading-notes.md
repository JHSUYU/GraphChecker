## Hadoop unit workloads read in full

- `hdfs-11741/.../TestCausynthExpiredBalancerKey.java`: Balancer caches an old current block key, NameNode rotates and DataNodes update or expire; the target DataNode rejects a token signed with a key it lacks. The test stabilizes random key IDs before recording and has explicit request/tick markers.
- `hdfs-17897/.../TestCausynthStripedChecksum.java`: a three-DataNode XOR 2+1 striped file, a cached DFSClient data encryption key, two NameNode rotations, and explicit DataNode key refreshes precede `getFileChecksum`. It pins the pre-recording key set so separate replay JVMs use the same IDs. The one-minute key update/lifetime settings create an expiry window that default settings would miss.
- `hdfs-17899/.../TestBalancerWithEncryptedTransfer.java`: only `testEncryptedBalancer1` installs the Causynth workload. It pins NameNode/DataNode keys at the Balancer hook before KeyManager's constructor snapshot, rotates twice during recording, pushes key updates through heartbeats, and lets a failed heartbeat keep a DataNode stale so Balancer continues. `testEncryptedBalancer0` and `testEncryptedBalancer2` are ordinary wrappers around `TestBalancer` methods.
- `hdfs-17899/.../TestCausynthDataTransferRpcFailure.java`: a two-DataNode NN/source/target workload. It rotates NameNode keys twice, attempts target then source heartbeat refresh, models an I/O-failed target refresh as preserving old keys, and calls `source.transferBlock` to the target. The expected fatal path is a transfer/data encryption failure downstream. The test pins key IDs and uses request markers for heartbeat and transfer.
- `hdfs-17899/.../TestExternalStoragePolicySatisfier.java`: the 2,122-line suite covers external SPS setup, Kerberos/keytab, queue limits, storage movement across COLD/SSD/NVDIMM/WARM policies, pinned and low/excess redundancy blocks, directory and empty-file xattr cleanup, and metrics. Its GraphChecker-specific `testCausynthSpsKeyRefreshRpcFailure` starts a one-DataNode encrypted-transfer cluster, pins NameNode/DataNode block-key IDs before recording and waits for the SPS KeyManager's initial daemon refresh. During recording, the NameNode rotates twice and a heartbeat updates the target DataNode; an SPS `updateBlockKeys` RPC failure leaves the SPS KeyManager stale, then external SPS attempts to move the block to SSD. Request/tick marks distinguish the failed refresh from the later movement. The test uses reflection to prune unpinned keys so replay JVMs share a stable key domain.

Still unread in full: the two 2,000-plus-line `TestBalancer.java` copies. `TestCausynthStripedChecksum` and the three 17899 tests have different intervention points; they should not be treated as one generic stale-key workload.

## GraphChecker arm implementation read in full

- `smt/Arms.java`: a WIRE arm comes only from a producer export in a session whose own attach paired that producer with the consumer, then follows nested handoff symbols to a fixed point. It carries the producer's decisions before delivery, a guard over the delivery replay's valued non-clock roots that were varied or named in the expression, and an attestation flag requiring an instrumented activation row. A STATE alternative is the last write of one writer occurrence and is admitted only if that writer is attested and known concurrent with the reader; the observed writer remains an arm even when not attested. Same-thread event order and known causal-anchor ancestry exclude concurrency; missing or lost provenance never proves concurrency. `exactlyOne` selects one arm. This is the precise GraphChecker rule; the HBase SMT files are hand-composed causal slices and do not claim recorded WIRE/STATE arms from this implementation.
- `compose/ClaimPolicy.java`: asks Z3 for each root valuation, captures selected path and family arms, and refuses solver errors or undecided valuations. It probes every path with roots free to detect internally contradictory disjuncts, and requires the recorded-valuation UNSAT core to name a valuation pin before a root flip can establish healthy-to-fatal polarity. Mechanism attribution asks whether pinning observed STATE versions or WIRE arrivals makes the witness UNSAT, then checks moved roots and necessary clock skew. A clock is necessary only if pinning all cells to their recorded instants makes the query UNSAT. An unattested producer arm cannot support a moved root. Thus `sat/unsat` on a hand-built HBase formula establishes a causal possibility and control, but it does not itself confer a GraphChecker claim kind or a recorder-backed witness.
- `compose/ComposedFamilies.java`: turns `Arms` candidates into one selector per distinct delivery and an exactly-one family guarded by the selected path. Each selected arm conjoins its producer prefix, recorded root guard, and delivered expression equality; missing expression or unstatable prefix refuses that arm, and an unfilled bound WIRE slot is blocking. STATE choices group all reads of one named location in one reader occurrence, take the last write from each eligible writer occurrence, and open a case split only with at least two alternatives. A heap owner identified only by class gets no alternative writer because it aliases instances. Unpaired or outside-closure interactions are diagnostic rather than invented joins.
- `explore/ClosurePlanner.java`: starts demand at the annotated target's fatal predicate and static guard branches, then reaches only attaches/reads whose symbols feed that demand. For each demanded boundary, it follows recorded paired producers or eligible writes and static candidate export/write sites, iterating to a fixed point; static candidates may expose a branch that the seed skipped. A static region with no activation is diagnostic and cannot become a replay task. A demanded occurrence with no session activation, or truncation past the 64-task default, is blocking. The candidate's flip sites come from guards of the contributed write/export, and each task is keyed by focused occurrence rather than request envelope.
- `GraphCheckerMain.java`: the static and instrumentation entry point registers one Soot whole-program transform, disables Soot's call graph, and keeps project production output directories as the application scope in both passes. Test output directories remain on the classpath for discovery but are rejected from application scope, including Soot trailing arguments. The classpath expansion sorts wildcard jars and puts project outputs before dependencies. This explains why the customized recorder needs a compatible project build before it can weave workload code.

## GraphChecker tests read in full

- `PlanTest.java`: selector resolution uses the *k*th seed-order activation on the specified component and API. A declared selector absent from the seed becomes an unresolved/lost declaration for `DECIDE` to report, rather than a guessed occurrence.
- `NoFabricatedChainElementTest.java`: an empty expression stays absent; explicit fault markers read recorded polarity when present; a target reach requires the declared site/occurrence/outcome event, rather than any thrown exception.
- `BranchDecisionRecordingTest.java`: both binary and multiway decisions publish one branch row and target-reach event at the same site; the selected switch successor is a replay authority. A concrete decision at the exact target site can still establish reach. Guarded-store metadata preserves comma-containing site IDs as separate tab-delimited fields.
- `SymbolicRootPolicyTest.java`: declarations alone authorize symbolic root reads and wall-clock tags. Undeclared field reads are concrete, explicit workload fault markers remain symbolic without a declared mint, and wire cut ports propagate an existing expression without minting a new root. A declared cell selects its static write sites; proven exact local copies can rename a declared accessor return onto the materialized local. Site and callee declarations have different scopes, and unplanned or never activated roots are refused by name.
- `OccurrenceAddressIsNotARequestTest.java`: root admission is by occurrence address (node/epoch/region/execution index), not a matching request or message envelope. Request/API and sender provenance are retained as context; an inbound header cannot overwrite the receiver's execution source. Missing send scope reports which source/request fields are absent, and an unaddressed loop-body root is refused.
- `RegionGraphOccurrenceKeyTest.java`: occurrence-key parsing refuses activation suffixes and incomplete addresses; a shared address blocks only when its region is kept in closure. A wire attach is admitted by a declared call site/callee capture in the recording, not a run-specific wire transaction ID. The static scope map lists both observed and skipped candidate writers with their innermost regions, leaf/carrier aliases, target/export sites, and post-dominance guard arms; it does not claim which activation actually wrote a value. The Soot fixture checks that original site IDs survive hook insertion.
- `ConcolicHookAbiTest.java`: parses the Soot hook catalogs and reflects each woven public static runtime method and signature; checks the external workload caller list too. The JUnit runner fixture verifies Jupiter and JUnit 4 lifecycle order, propagation of a test assertion after teardown, and explicit refusal of an absent workload method.
- `ContractTest.java`: round-trips occurrence addresses, selectors, interaction endpoints, every row kind, expression tables, and session layout. Its invariant table exercises blocking and diagnostic gaps for missing activation provenance, unstated reads, absent expression refs, duplicate events, sort conflict, outcome/term disagreement, unstated versions, fabricated placeholder writes, undeclared or unspelled root mints, and missing fatal-polarity target terms.
- `ManualMintStatesItsValueTest.java`: manual and clock root mint rows state this run's observed value even during focused replay. The model applies clock deltas to that observed instant, roots at their mint occurrence, and flips at their addressed target occurrence; admission requires all moved root mints and an unbroken prefix. A configured source assignment applies only at the right node/epoch, while every execution of one configured site shares its variable without a frozen occurrence count.
- `RowRuntimeTest.java`: scope propagation reaches queued IPC work, executor tasks, and daemon ticks with stable root context. Exports/attaches pair by recorded handle or correlation, never by the last producer on a port. Decision, state read/write, placeholder, root mint, target, gap, and expression rows round-trip through a session. Placeholder reads use VM location/version and distinguish observed from mint version; a missing VM location yields a gap. Branch terms preserve the jump predicate and observed arm, while target terms use fatal polarity. Frame and region journals distinguish loop turns and started siblings without relying on thread scheduling or incidental calls; stray region pops are detected as blocking imbalance.
- `ExploreTest.java`: synthetic sessions pass through the actual ExploreMain and Z3 worker. A nested guard chain is explored one decision per wave and an arm is owed once per planned occurrence, even if later sessions add paths. A wire handoff answer must be one producer actually paired to that consumer before export, and an unpaired control is marked unproducible. Undeclared integral roots are pinned, declared bounds are relative to the seed, and clocks become deltas planted at their own mint occurrence. Closure starts from the declared target and follows observed read versions, recorded wire producers, and static candidate writers whose guarded writes a seed skipped. Wire pair replacement can fork an epoch; another STATE writer is an arm, while unretained regions and unstable occurrence slots are named separately. Container read dependencies use the state they rest on and the producer's AssocState sort.
- `ComposerTest.java`: constructs recorded sessions to test the full path formula, root valuations, and wire/state pairing families with Z3 and ClaimPolicy. A selected path keeps its own branch outcomes, fatal predicate, stated reads and joins; producer arms are guarded by their own prefix, and nested handoffs close transitively. Concurrent state writers become alternatives only when causal order permits; the actual recorded writer is one arm and a different eligible writer is a STATE_PAIRING_FLIPPED witness. No attested producer or missing provenance blocks a claim. The tests exercise fail-closed gaps for absent expressions, undeclared or unvalued symbols, conflicting sorts, unsupported projections, and missing attach evidence. They also check clock cells by minted symbol, marker and integral domains by root kind, versioned placeholder reads, reference null identity, quantifier-free indexed-list mutations with bounds, and omission of unreached read equations. Activation order comes from thread keys and recorded handoffs; a separate unlinked thread remains concurrent.
