# HBase findings 19–36: coordination and exception impact audit

Audited against `/u/vnr3ne/hbase` on 2026-09-19. `pass` means that the current code and targeted test show a coordination-state mismatch reaching an exception that fails a public operation or essential server/backup worker. `insufficient` means that the observed exception or local defect is real, but the test/source chain does not establish the full requested impact. `fail` means that the cited exception is expected, caught/retried, or the claimed behavior is not established as a correctness bug. This audit does not establish worldwide novelty.

All 18 test classes have a current Surefire XML report. Ten red tests use a deliberate final healthy-state assertion after asserting the reported exception; their red status is evidence of the *current* defect, not an uncontrolled test crash. See each test and report for the exact assertion.
