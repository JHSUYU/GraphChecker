# Split at the parent's region-ID millisecond

`split-equal-clock.smt2` manually joins the master clock path, first-daughter constructor values, and the parent's existing `RegionStates` entry. This is a GraphChecker-style relational model, not recorder output.

The procedure copies the parent's table and start key into the first daughter at [`SplitTableRegionProcedure.java:138-145`](/u/vnr3ne/hbase/hbase-server/src/main/java/org/apache/hadoop/hbase/master/assignment/SplitTableRegionProcedure.java:138). Its [`getDaughterRegionIdTimestamp`](/u/vnr3ne/hbase/hbase-server/src/main/java/org/apache/hadoop/hbase/master/assignment/SplitTableRegionProcedure.java:264) increments the parent ID only when `now < parentId`. At equality it returns the parent ID. [`ModifyRegionUtils.java:101-108`](/u/vnr3ne/hbase/hbase-server/src/main/java/org/apache/hadoop/hbase/util/ModifyRegionUtils.java:101) throws `DoNotRetryIOException` when a candidate's encoded name already has a `RegionStateNode`.

Run `/tmp/hbase-z3/usr/bin/z3 -smt2 split-equal-clock.smt2`. The expected answers are `sat` for `now = parentId`, followed by `unsat` for `now > parentId` with the same collision target. The model treats a region name as `(table, startKey, regionId)`, with no accidental MD5 collision for two distinct names. It models this particular parent/daughter equality and does not exclude unrelated hash collisions.

The new [`testSplitWhenMasterClockEqualsParentRegionId`](/u/vnr3ne/hbase/hbase-server/src/test/java/org/apache/hadoop/hbase/master/assignment/TestSplitTableRegionProcedure.java:153) constructs an actual procedure after injecting a clock equal to the parent's region ID. The red [Surefire report](/u/vnr3ne/hbase/hbase-server/target/surefire-reports/org.apache.hadoop.hbase.master.assignment.TestSplitTableRegionProcedure.txt) records one test, one expected assertion failure, and the cause `DoNotRetryIOException: Encoded region name collision detected`, with frames in `ModifyRegionUtils.java:108` and `SplitTableRegionProcedure.java:145`. The test is deliberately a regression specification: it fails while the bug is present.
